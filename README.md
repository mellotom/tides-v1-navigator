# tides-v1-navigator

travelers guide for managing gravity: a one-page reference for the **mutable instruments tides** (2014 version), firmware v1.1. buttons and LEDs, the three modes and ranges, shape / slope / smoothness, the uni and bi outputs, clocked / pll mode, calibration, firmware updates, how each mode reads a gate, and the peacocks easter egg, with diagrams.

sources: [mutable instruments documentation](https://pichenettes.github.io/mutable-instruments-documentation/modules/tides_original/) and the open-source firmware.

part of the [travelers guide welcome center](https://mellotom.github.io/travelers-guide/).

not affiliated with mutable instruments.
